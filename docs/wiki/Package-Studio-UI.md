# @metastruct/studio-ui

`@metastruct/studio-ui` provides reusable authoring and inspection surfaces for a schema-driven studio.

## Abilities

- Display entity tree navigation.
- Provide layout and stepper shell components.
- Provide a schema field canvas for editing or inspecting field definitions.
- Re-export platform UI functionality for studio composition.

## Stage Role

This package supports authoring Stage 1 data models, Stage 2 UI layouts, and eventually Stage 3 questionnaire steps in a visual studio.

## Current Boundary

The components are reusable UI surfaces; complete persistence of studio edits and a full end-to-end generation workflow are still being developed.
